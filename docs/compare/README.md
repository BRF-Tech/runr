# RunR compared

<!-- description: RunR compared with Google Cloud Run, AWS Lambda, Vercel, Knative and OpenFaaS, one page each, every statement about them linked to their own docs. -->

RunR is an open-source (MIT) serverless platform: functions, multi-file projects and containers on
Knative, on Kubernetes clusters you operate. These pages set it next to the platforms people
usually weigh it against, one at a time: what differs, with a link to the vendor's own
documentation next to every statement about it, and when each one fits.

| Page | Compares RunR with |
| --- | --- |
| [RunR vs Google Cloud Run](cloud-run.md) | Google Cloud's managed platform for containers, functions and jobs |
| [RunR vs AWS Lambda](aws-lambda.md) | The serverless compute service of Amazon Web Services |
| [RunR vs Vercel](vercel.md) | The hosted platform for web applications deployed from git |
| [RunR vs Knative](knative.md) | Knative on its own, the CNCF project RunR is built on |
| [RunR vs OpenFaaS](openfaas.md) | The functions platform for Kubernetes and single hosts, with community and commercial editions |

The landing page sets RunR next to Knative, Knative Functions, OpenFaaS, AWS Lambda and Vercel in
one table, with RunR's measured cold starts ([runr.sh](https://runr.sh/#compare)). The
documentation index is [docs/README.md](../README.md).

The statements about other platforms come from their documentation as read on the date each page
gives. Product names are trademarks of their owners; RunR is not affiliated with or endorsed by any
of them.
